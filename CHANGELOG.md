# Changelog

## 0.3.0

- Added journal validation and flattening into normalized entries.
- Added trial balances, dataset validation, CSV entry import, receivables
  aging, tax summaries, cash reconciliation, exchange conversion, transparent
  forecasts, and multi-statement report packs.
- Hardened JSON escaping and reciprocal-balance elimination.

## 0.2.0

- Added structured period and batch validation.
- Added dimensions, comparison variance, budgets, consolidation, cash-flow
  classification, ratio analysis, trends, anomaly detection, and currency
  scaling.
- Added HTML reports, deterministic benchmark fixtures, and a curated standard
  account directory.
- Expanded multi-target tests and CI with native coverage and guarded
  Mooncakes publishing.

## 0.1.0

- Added period-aware normalized debit/credit entries.
- Added account-to-line mapping with signed factors.
- Added balance sheet, income statement, cash flow, and management report kinds.
- Added deterministic CSV, JSON, and Markdown renderers.
- Added multi-backend checks and tests for the MoonBit 0.10.x toolchain.
